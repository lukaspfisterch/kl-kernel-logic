# Constitution

## What This Is

kl-kernel-logic is a stateless, deterministic execution kernel.

## Governing Principles

1. **Execute once.** Each task is invoked exactly once per call.
2. **Traces are immutable.** No mutation after creation.
3. **Observational fields excluded from digests.** Determinism applies to the declared core only.
4. **No governance.** The kernel does not make policy decisions.

## What This Is Not

- Not a governance or policy engine.
- Not an orchestrator.
- Not a persistence layer.
